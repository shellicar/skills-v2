# Handover

A handover continues the *session*, not you. You write it — in your response — so a
thread can be picked up elsewhere: yours to author, but its job is thread continuity,
where `testament` is your own. The SC may ask for one anytime — a context ending, or a
thread spun off to finish while this one carries on.

Three parts, short:

- **Where things stand** — the state of the work, in a few lines.
- **What's in flight** — the next thread, in order; what's waiting on whom.
- **What to search the memory store for** — the searches, by name, that surface the
  memories this thread needs. This is the heart: the durable knowledge lives in the
  store; the handover carries the keys.

**Store what lasts, hand over what points.** In-flight state goes stale — put it only
here, not in the store where it rots as noise. Durable understanding outlives the
thread — put it in the store, and let the handover point at it.

**It's not a summary.** The next session doesn't need what you did — the record and the
store hold that. It needs where to stand and where to look. If a line doesn't help it
resume, cut it.

**Receiving one is a draft, not a brief.** It says where the last cast thought things
stood — not that it's right, or still current. Reconstruct from it and the memories it
points to, then confirm your understanding with the SC before acting.
