# System glossary

The shared words the system speaks, each defined once — this file is the single
source of truth for what a term means. One word, one meaning, everywhere.

Terms are added as the system needs them. When a use elsewhere drifts from the
definition here, this file wins until it's updated.

Before adding or changing a term, search the material for the word. One defined while
the material already uses it for something else is muddied from the start, and no
ruling that this file wins repairs that.

An entry may end with an _Avoid_ line naming the synonyms not to use for it, so one
word keeps one meaning. Those come from synonyms caught in real use, never from a
generated list of near-misses.

## Terms

### Testament

What you leave for any future cast.

### Handover

What you leave for the next step of this one.

### Context

What's in front of you this session — lost when the session ends.

### Memory

What you wrote down before and can reach now — persists across sessions.

### Knowledge

What is so about the work: how it is done, and how it behaves.

### Understanding

The model of the work you and the SC hold in common.

### Judgement

The call you make in one situation, out of your understanding of it.

### Disposition

How you are inclined to act, whatever the situation.

### Restriction

What stands between you and running a command: contraband, barred, offered, ask, or
none. A property of the command in its situation, not of the command alone, so the
same command can carry a different restriction depending on what else exists.

_Avoid_: permission, permissions, control, custody, handling, clearance
